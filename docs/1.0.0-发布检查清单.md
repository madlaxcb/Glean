# Glean 1.0.0 发布检查清单

> 本清单用于准备 1.0.0 正式发布。本阶段只更新发布文档，不修改代码中的版本号、二进制名称或安装包名称。

## 发布口径

- [ ] 明确 Release 标题为 `Glean 1.0.0 / 拾光 1.0.0`。
- [ ] 在最终发布前确认当前代码版本仍为 `0.3.0`，并决定何时切换到 `1.0.0`。
- [ ] 记录当前产物实际名称：`glean-spike.exe`、`glean-spike-setup.exe`。
- [ ] 记录规划名称与实际名称的差异，避免下载说明写错文件名。
- [ ] 确认 Release 是否标记为正式版，而不是预发布版。

## 功能验收

- [x] 添加、编辑、重命名、删除 RSS/Atom 订阅。
- [x] 文件夹分组、同组拖拽排序和排序持久化。
- [x] 条目已读/未读、星标、浏览器打开和右键刷新。
- [x] 全部刷新、单订阅刷新、停止刷新和后台刷新。
- [x] 全文抽取、文章阅读、图片策略和本地图片缓存。
- [x] FTS5 搜索，验证中文标题和正文子串搜索。
- [x] OPML 导入/导出，验证追加和覆盖两种模式。
- [x] 主题、字体、布局、窗口位置和托盘状态持久化。
- [x] HTTP/SOCKS5 代理、单实例和 WebView2 缺失提示。
- [x] 插件安装权限确认、更新权限扩大警告和插件启停。
- [x] 插件代理、凭证注入、Pixiv/Bilibili 适配器基本流程。
- [x] AI 摘要/翻译状态、错误提示和结果持久化。
- [x] 缩略图仅加载可见行，切换列表后内存不持续增长。

## 性能与稳定性

- [x] 已验证 27,457 条目场景下缩略图内存不再持续增长。
- [x] 修复后主进程采样约 120MB，缩略图缓存保持在可视行规模。
- [ ] 测量冷启动时间并记录机器配置。
- [ ] 测量空闲主进程、WebView2 子进程和进程组总内存。
- [ ] 测量 100 个订阅全部刷新耗时。
- [ ] 测量万级条目滚动体验和长时间运行稳定性。
- [ ] 连续打开 50 篇文章后检查主进程和 WebView2 内存。
