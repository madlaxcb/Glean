# Glean / 拾光 用户手册（1.0.0 发布准备稿）

> 本手册按 1.0.0 发布口径编写。当前构建仍使用仓库现有的 0.3.0 版本号、`glean-spike.exe` 和 `glean-spike-setup.exe` 命名；正式发布前需要以发布清单为准完成同步。

## 1. 系统要求

- Windows 10 1809 或更高版本、Windows 11。
- Windows WebView2 Evergreen Runtime。Windows 11 通常已预装；缺失时从微软官方下载并安装。
- x64 Windows。当前安装器只支持 x64-compatible 系统。
- 首次安装需要管理员权限；便携模式需要程序目录可写。

## 2. 安装与启动

### 安装包

1. 下载 Windows 安装包。
2. 运行安装程序并选择安装目录。
3. 如果安装程序提示缺少 WebView2，先安装 WebView2 Runtime，再启动 Glean。
4. 安装完成后从开始菜单、桌面快捷方式或安装目录启动程序。

安装器默认将程序放在 Windows 程序目录，程序数据仍默认保存到当前用户的 `%APPDATA%\Glean\`。

### 便携模式

在 `glean-spike.exe` 同目录创建 `data` 文件夹后启动程序：

```text
Glean\
├─ glean-spike.exe
└─ data\
```

便携模式会把数据库和配置保存到 `data\`，适合移动硬盘、多账号隔离和整体备份。程序目录必须可读写；安装在 `Program Files` 时，建议改用用户目录或确认写入权限。

## 3. 首次使用

1. 在顶部 URL 输入框粘贴 RSS 或 Atom 地址。
2. 点击「添加订阅」。
3. 在导航区选择订阅，点击「刷新全部」或使用该订阅右键菜单中的「刷新订阅」。
4. 在条目列表中点击文章标题阅读内容。

订阅可以重命名、编辑 URL、删除、移动到文件夹，也可以进入整理模式在同一分组内拖拽排序。

## 4. 阅读与条目操作

- 点击条目后在阅读区查看标题、正文和原文链接。
- 条目右键菜单支持标记已读/未读、星标、在浏览器中打开。
- 支持对有原文地址的条目执行「刷新该贴」；插件订阅会复用订阅的代理、认证和请求头配置。
- 删除订阅时，星标条目会保留，普通条目会随订阅删除。
- 列表使用虚拟滚动；缩略图只为当前可见区域加载，以控制内存占用。

### 快捷键

| 快捷键 | 操作 |
|---|---|
| `j` | 下一篇条目 |
| `k` | 上一篇条目 |
| `r` | 刷新 |
| `s` | 切换星标 |
| `t` | 切换深浅主题 |

## 5. 搜索、导入与导出

- 搜索框支持标题和正文全文搜索，中文支持子串匹配。
- 使用「导入 OPML」批量导入订阅，可选择追加或覆盖现有订阅。
- 使用「导出 OPML」备份订阅列表，或迁移到其他 RSS 阅读器。
- 导入前建议先导出当前 OPML，并备份数据库文件。

## 6. 刷新与自动刷新

- 「刷新全部」在后台执行，不阻塞列表和阅读操作。
- 刷新过程中可以使用「停止刷新」终止后续任务。
- 在设置中配置全局自动刷新间隔；设置为 `0` 表示关闭全局自动刷新。
- 可以为单个订阅设置独立刷新间隔。
- 失败的订阅会在错误日志中留下原因；网络恢复后可以再次手动刷新。

## 7. 图片、缓存与离线阅读

设置中的图片策略：

- **拦截**：不加载正文图片，适合节省流量和内存。
- **按需**：默认不加载，阅读当前文章时可手动显示图片。
- **允许**：允许正文图片按文章内容加载。

正文 HTML 和图片可以写入本地缓存。启用缓存后，部分文章在无网络时仍可阅读；缓存目录可在设置中查看或调整。缩略图缓存和正文图片缓存是两套机制，清理正文缓存不会影响订阅数据库。

## 8. 主题、布局与托盘

- 设置深色/浅色主题和主题色。
- 调整阅读字体大小、行宽、导航区宽度、列表区宽度和缩略图大小。
- 窗口位置、大小、最大化状态以及设置窗口几何信息会保存到配置文件。
- 关闭主窗口可以最小化到系统托盘；从托盘可以恢复窗口、刷新订阅或退出程序。
- Glean 使用单实例锁，重复启动时不会创建第二个实例。

## 9. 代理、插件与 AI 增强

### 代理

在设置中配置 HTTP 或 SOCKS5 代理。插件或订阅启用「使用代理」后，相关请求会按配置通过代理发送。保存前程序会规范化并校验代理地址。

### 插件

从「插件管理」安装文件夹或 ZIP 插件。安装前会显示插件信息和能力列表；确认权限后才会写入插件目录。更新插件时，如果新增能力，会显示权限扩大警告。

插件数据默认位于：

```text
<data_dir>\plugins\<plugin-id>\
```

插件凭证由 Host 注入请求，插件脚本不能直接读取凭证明文。只安装可信来源的插件。

### AI 增强

在设置中配置兼容的 API 地址、模型、API Key 和目标语言。AI 增强在后台执行，支持摘要和翻译；失败时会同时在状态栏和错误日志中提示。API Key 只应保存在本机配置中，不要提交到仓库或分享给他人。

## 10. 数据位置与备份

默认数据目录：

```text
%APPDATA%\Glean\
├─ glean.db
└─ config.json
```

建议在升级或迁移前退出 Glean，然后备份整个目录。使用便携模式时，备份程序目录下的 `data\`。不要在程序运行期间直接复制 SQLite 数据库。

## 11. 故障排查

### 阅读区空白

确认 WebView2 Runtime 已安装并重启 Glean。若只有某个站点空白，先尝试「刷新该贴」或在浏览器中打开原文。

### 订阅刷新失败

查看错误日志，确认 URL、网络、代理和插件状态。对于需要登录的站点，检查插件凭证和插件的「使用代理」开关。

### 图片不显示

检查图片策略是否为「拦截」，或在「按需」模式下点击文章中的显示图片操作。远程图片也可能因站点权限、Referer 或网络限制失败。

### 内存占用异常

先停止刷新并关闭不需要的文章窗口，确认使用的是最新构建。当前版本只为可见列表加载缩略图；如果内存仍持续增长，请保留 `glean-debug.log`、复现步骤和任务管理器进程组截图。

### 数据迁移

退出旧版本后复制 `%APPDATA%\Glean\` 或便携模式的 `data\` 到新环境。若数据库启动检查发现损坏，程序会尝试使用 `.db.bak` 恢复。

- Glean 构建版本和 Windows 版本；
- 复现步骤和预期/实际结果；
- `glean-debug.log` 中相关日志；
- 是否使用代理、插件、图片缓存或 AI 增强；
- 不包含 API Key、密码或 Cookie 的截图和配置说明。
